# Portfolio 4: NoSQL and Advanced Data Models

## 1. Overview

This portfolio explores how NoSQL databases can support ShopEase, a fictional e-commerce store that sells computer accessories.

## 2. Objectives

- Understand the differences between relational and NoSQL databases.
- Model product information using a document-based structure.
- Explain why a NoSQL database may be suitable for some ShopEase operations.

## 3. Case Study

ShopEase sells products such as wireless mice, keyboards, laptop stands, USB-C hubs and headphones. Product details can vary, so a document-based model may allow flexible product attributes.

## 4. Implementation

The NoSQL data model, sample documents, implementation steps and supporting evidence will be documented here.

## 5. Results and Observations

This section will describe the implementation results and compare the document model with the relational approach used in the earlier portfolios.

## 6. Conclusion

This portfolio will evaluate the suitability of NoSQL for ShopEase's product catalogue and explain its advantages and limitations.
