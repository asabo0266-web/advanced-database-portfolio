## Project Overview

This repository contains five portfolios exploring database design, SQL query optimisation, transaction management, NoSQL data modelling, and distributed and cloud database concepts. All five portfolios use ShopEase, a fictional e-commerce business selling computer accessories.

## Portfolio Structure

1. **Portfolio 1 — Database Design:** Requirements, ER modelling, relational schema, keys, constraints, and normalisation.
2. **Portfolio 2 — Query Optimisation:** SQL queries, execution plans, indexing, and performance analysis.
3. **Portfolio 3 — Transactions and Concurrency:** Commit, rollback, isolation, and concurrent transaction behaviour.
4. **Portfolio 4 — NoSQL:** MongoDB document modelling, product data, and filter queries.
5. **Portfolio 5 — Distributed and Cloud Databases:** Local MongoDB replica-set configuration, distributed database concepts, and a proposed cloud architecture.
